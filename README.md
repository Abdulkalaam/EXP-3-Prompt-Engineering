## EXP-3: Prompt Engineering

## Aim

To evaluate and compare the performance of prompting tools across different AI platforms such as ChatGPT, Claude, Google Bard (Gemini), Cohere Command, and Meta AI for a common use case. The experiment focuses on text summarization and compares the response quality, clarity, accuracy, completeness, and user experience of each platform.

## Objective

- To understand how the same prompt produces different responses on various AI platforms.
- To analyze the effectiveness of prompt engineering.
- To compare the strengths and limitations of ChatGPT, Claude, Gemini, Cohere Command, and Meta AI.

## Theory

Prompt engineering is the process of designing and refining instructions given to an AI model in order to obtain accurate, relevant, and useful responses. The quality of an AI-generated response depends greatly on how the prompt is written. A well-designed prompt includes a clear task, constraints, and expected output format.

## Example:

- Weak Prompt: “Summarize this.”
- Strong Prompt: “Summarize the following paragraph in exactly 50 words, preserving the main idea and key supporting points.”

Different AI platforms are trained using different datasets, architectures, and optimization techniques, so they may produce different outputs even when given the same prompt.

## Tools Required

- ChatGPT
- Claude
- Google Bard (Gemini)
- Cohere Command
- Meta AI
- Internet connection
- Web browser or mobile application

## Algorithm

1. Select a common AI task (text summarization).
2. Prepare a paragraph of approximately 150–200 words.
3. Use the same prompt on all five AI platforms.
4. Record the output generated by each platform.
5. Compare the responses using evaluation criteria:
   - Accuracy
   - Clarity
   - Completeness
   - Conciseness
   - Readability
   - Response speed
6. Analyze the observations.
7. Draw the final conclusion.

## Input Text

Artificial Intelligence (AI) is transforming industries such as healthcare, education, finance, and transportation. AI systems can analyze large amounts of data, recognize patterns, automate repetitive tasks, and support decision-making. Recent advancements in generative AI have enabled computers to create text, images, audio, and software code. Organizations are adopting AI tools to improve productivity and customer experience. However, AI also introduces challenges such as privacy concerns, bias in algorithms, job displacement, and ethical issues. Responsible development, transparency, and human oversight are important to ensure that AI benefits society while minimizing risks.

## Prompt

“Summarize the following paragraph in exactly 50 words while preserving the main idea and the most important supporting details. Use simple English suitable for a first-year engineering student.”

## Observations

- ChatGPT produced the most balanced summary with excellent structure and accuracy.
- Claude generated the most natural and human-like wording.
- Gemini used the simplest language, making it suitable for beginners.
- Cohere Command produced the shortest response and omitted some supporting details.
- Meta AI provided a clear and accurate summary but was slightly less organized than ChatGPT and Claude.

## Advantages of Prompt Engineering

- Improves response accuracy.
- Reduces ambiguity.
- Produces structured outputs.
- Saves time by generating relevant information quickly.
- Allows control over tone, length, and formatting.

## Applications

- Content summarization
- Report generation
- Technical question answering
- Programming assistance
- Education and tutoring
- Customer support automation
- Research and documentation

## Result

The experiment successfully compared the prompting capabilities of ChatGPT, Claude, Gemini, Cohere Command, and Meta AI using the same summarization prompt. ChatGPT and Claude delivered the highest-quality summaries in terms of accuracy, coherence, and completeness. Gemini was the easiest to understand, while Cohere Command generated the most concise output. Meta AI produced a good overall summary with acceptable clarity and detail. The experiment demonstrates that effective prompt engineering significantly improves AI-generated responses and that different AI platforms exhibit different strengths for the same task.
